# Project screenshot folders

The project-details modal discovers screenshots from a folder named after each
project id. File names do not need to follow a specific convention; they are
sorted naturally (for example, `screen-1.png`, `screen-2.png`, `screen-10.png`).
Add any supported image files to the matching folder:

- `public/projects/tnp-oms/`
- `public/projects/warehouse-internship/`
- `public/projects/coffee-shop/`
- `public/projects/silver-thatch/`

The existing single screenshot in `public/projects/` remains the fallback until
project-specific screenshots are added.
