# Tech Stack Icons

These SVG files are exact artwork from the official
[Tech Stack Icons](https://www.tech-stack-icons.com/) library,
[tech-stack-icons@3.7.1](https://www.npmjs.com/package/tech-stack-icons/v/3.7.1),
by Eugenio Ciccale. The package declares the MIT license.

Source: https://cdn.jsdelivr.net/npm/tech-stack-icons@3.7.1/dist/index.js

The original SVG geometry, colors, gradients, and view boxes are unchanged.
Serving the artwork as individual local images avoids downloading the entire
icon catalog or fetching logos from a third party during page visits.

Mapping: HTML → html5; CSS → css3; TailwindCSS → tailwindcss;
JavaScript → js; PHP → php; Firebase → firebase; TypeScript → typescript;
Vue.js → vuejs; Laravel → laravel; MySQL → mysql; React.js → react.

Additional Skills assets: nuxtjs, nextjs, nodejs, python, django, mariadb,
sqlite, git, github, electron, figma, canva, photoshop, premierepro, openai,
copilotgithub, gemini, claude, and vitejs. Files with a `-dark` suffix use the exact
official dark-background variant so monochrome logos remain legible. Other
files use the original light variant and retain the brand's source colors.

Inertia.js, Capacitor.js, Microsoft Office, and Xampp are not present in this
version's catalog. The Skills interface explicitly maps the first three to
the user-provided assets documented in `/more-icons/NOTICE.md`; those files
are separate from this library. ChatGPT and Codex use the library's OpenAI
mark with their own accessible labels. There is no distinct Codex glyph in
this catalog version.
